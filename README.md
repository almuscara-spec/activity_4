# Finding the Hypotenuse  of a Triangle

## Description
This Python program calculates the length of the hypotenuse of a triangle.

## How to Run
-Make sure Python is installed on your computer.                                       
-Open the Python file.                                  
-Run the program.                                    
-Enter the length of the first side or side A.                           
-Enter the length of the second side or side B.                             
-The program will display the length of the hypotenuse.

## Input Needed
The program requires two inputs

-Length of the first side or side A                  
-Length of the second side or side B

Both values should be numbers

## Sample Output
```text
Enter the length of side A: 3
Enter the length of side B: 4
The hypotenuse is: 5.00
```
